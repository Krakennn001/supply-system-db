# Система учета поставок (Университетский проект)

База данных для небольшой строительной фирмы, занимающейся ремонтом помещений, которая закупает необходимые детали у разных поставщиков.
Реализована на PostgreSQL 18.

## Функционал 
* Спроектирована схема БД (4 таблицы в нотациях Чена и "Воронья лапка").
* Создана модель БД (с ограничениями).
* Внесены тестовые данные.
* Созданы представления для разных отделов.
* Разграничены права доступа (роли: Директор, Экономист).
* Написаны хранимые функции для отчетов.
* Настроены триггеры.

## Как развернуть проект

1. Создайте пустую базу данных в PostgreSQL (например, `supply_system`).
2. Нажмите ПКМ по базе данных, затем нажмите Restore...
3. Укажите путь до database_dump.sql файла (Format: Custom of tar).
4. Нажмите Restore.
3. Готово.
